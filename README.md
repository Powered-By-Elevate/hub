# Hub

A configurable financial and operational dashboard. One build, any industry, any
software stack, any brand.

**Live demo: https://powered-by-elevate.github.io/hub/**

Six industries off one codebase: construction, schools, retail, manufacturing,
freight, software. The financial engine is identical in all six. What changes is
the unit of work the money is divided by, which is a contract, a campus, a store,
a production line, a truck or a product.

Branding, connected software, view levels and modules are all configuration. The
settings console exports the file a real deployment is built from.

Every company, person, project and figure in this demo is invented.

Source and runbook: `tools/hub/` in the Agentic OS repository.
